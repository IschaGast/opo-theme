Opo

A colorblind-safe, accessible color theme for editors, terminals and the web.

Opo is Sranantongo for to rise, to open, from the Surinamese national anthem.

How it is built

Opo starts from a single light palette in OKLCH. Dark and High Contrast are derived from it, and every variant has to pass the same checks before any theme file is written.

The values

Two layers, as in most current themes: named hues, and the roles built on them (error, warning, success, info and the surfaces and text). Each color has its hex and OKLCH value per variant and its contrast against that variant's background. The selected variant is highlighted.

Terminal colors

Red, green and magenta are remapped to orange, teal and raspberry, which stay apart under every type of color vision deficiency. Shown for the selected variant.
